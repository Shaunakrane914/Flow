# Reproducing the follow-up

Use the recorded scientific package versions in the V2 environment record. The
natural development and external image archives are public institutional downloads.
Raw archives and derived graph tensors are kept in ignored local data directories;
no redistribution licence is inferred from public download availability.

On a fresh checkout, obtain the official archives and reconstruct the natural
development data before running the model comparisons:

```powershell
python scripts/fetch_official_archives.py
python scripts/recover_development_natural.py
python scripts/run_research_v2.py
python scripts/run_factorial_ablation.py
python scripts/prepare_locked_external.py
python scripts/run_locked_external_test.py
python scripts/probe_critical_throats.py --output experiments/topoflow_followup/critical_throats_verified
python scripts/prepare_throat_pilot.py
python scripts/train_throat_pilot.py
python scripts/check_full_volume_references.py
python scripts/compare_full_references.py
python scripts/build_followup_report.py
python -m unittest discover -s tests -v
```

The repository contains completed output directories, and runners refuse to
overwrite them. Reproducing in the same checkout therefore requires fresh output
paths or a separate local copy with generated output directories omitted. Do not
delete the committed evidence in the working checkout. Some ingestion and pilot
scripts use the declared default paths rather than accepting arbitrary paths.

The recovery helper reconstructs natural scans only. The original benchmark
manifest also contained synthetic specimens; those were excluded from all V2
natural and follow-up experiments. A fresh natural-only manifest will have a
different file hash even if its canonical natural graphs are identical. Run V2
again on that manifest before reusing its two compatible ablation cells; the
ablation script intentionally checks that its source V2 manifest hash matches.

Expected scope is 24 accepted development crops and 32 external crops with the
declared settings, subject to the observed extraction outcomes. Record failures
rather than manufacturing those counts. The critical-throat prototype selects
eight development graphs and four external graphs deterministically. Guidance
and response labels are generated by the declared PNM. Full-image published
reference values are never assigned to crops.

The historical run added two equally guided control architectures after seeing
the first external prototype results. That sequence is recorded in the protocol
and report. A fresh rerun evaluates the final six-architecture set together;
rerunning does not turn the already examined external scans into a new untouched
test set. Exact scores may also depend on scientific-library and extraction
versions, rather than only on the seed list.
