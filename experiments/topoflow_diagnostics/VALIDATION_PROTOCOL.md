# Prospective follow-up protocol — not executed

This protocol is separate from the completed comparative manuscript. Its
hypotheses come from a post-hoc analysis of five already inspected scan groups.
It supplies no new evidence of generalization or publication readiness.

## Primary hypothesis and data

Test whether guided-GAT minus affine-pressure top-throat loss increases with
geometric shortest-path tortuosity on previously unexamined source specimens.
Use a continuous association; do not fit a threshold or switching rule to
S2/S4/S6/S7/S8. Degree CV, alignment and cut density remain secondary, including
their conflicting signs in the current analysis.

Before looking at new intervention outcomes:

1. Establish source provenance, licences and distinct physical specimen IDs.
   Additional crops of the present scans cannot provide the new independent
   units. Record any uncertainty about repeated scans of the same specimen.
2. Lock an operational target of at least eight new specimen groups and fixed
   crop positions. Eight is a data-collection target, not a power calculation;
   statistical power must be assessed from independent development evidence.
3. Freeze source IDs, checkpoints, geometry definitions, extraction settings,
   eligibility, tie-breaking, restriction doses and analytical controls.
4. Save all geometry-only scores and selections before obtaining flow labels.
5. Evaluate the scan/specimen-macro top-three actual loss at 50% restriction and
   the association with tortuosity. Use specimen-level inference and report all
   planned secondary comparisons; avoid intervention-level pseudo-replication.

## Calibration is a separate experiment

Fit any amplitude or leverage calibration only to newly defined development
data with parent-group cross-fitting. Define the selection mix and error
weights before fitting; report whole-pool MAE, the fixed <0.1 / 0.1–1 / ≥1 pp
strata and the primary model's top/random/low groups. Select settings without
examining the new specimen test outcomes. The current five scans cannot be
relabelled as untouched validation after selecting a calibration using them.

## Physical reference gate

Before claiming realistic permeability or clogging accuracy, reproduce reference
flow on matching image volumes with documented orientation, domain length/area,
pressure conditions, segmentation, viscosity and boundary/reservoir treatment.
The current original-network shape-factor checks do not satisfy this gate. If
matched voxel-flow or measured references are unavailable, retain the explicit
cylindrical-PNM scope in the title, abstract, results interpretation and conclusions.

Do not apply a fitted factor of four or select the diameter definition that
happens to approach the S1/S5 reference values. A different declared closure
requires new targets, consistency checks and a fresh evaluation protocol.
